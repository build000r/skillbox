## Technical response bank

### “Why not a raw VPS?”

A raw VPS is the correct answer when minimum machinery matters most. Skillbox is
the reference shape for operators who want homes, overlays, runtime declarations,
and checks maintained as one inspectable system.

### “Why not DevPod/Coder/Gitpod?”

Those categories optimize environment/remote-editor or team-workspace jobs.
Skillbox intentionally optimizes one operator's durable machine. It does not
claim superior performance, cost, or security.

### “Is it secure?”

“Private” describes the Tailnet-first topology and operator-owned host. It is
not a certification. The docs expose the bind, firewall, posture, and recovery
contracts so an operator can inspect what is actually enforced.

### “Can I install it?”

Not from the current public license boundary. The repository is available for
reading and reference, but no public execution/reuse grant is defined. That
must be resolved before an adoption CTA is published.

### “Where are the users/testimonials?”

There are no permissioned customer reports. Current proof is a captured
operator walkthrough. The field-report contract forbids invented or
unpermissioned testimonials.

## Follow-up and measurement

### Definitions

- **Inspection proxy:** a repository-level referral or visit observation
  associated by source and time window. It does not verify that anyone read the
  guide or proof.
- **Qualified critique:** a linked, non-owner reply naming a concrete claim,
  control, proof gap, or missing check.
- **Demand signal:** an unsolicited explicit request for permission or a public
  usage grant. Stars, visits, generic praise, and critique do not count.
- Missing metrics are `unavailable`, never zero. Do not calculate an
  impression-to-visit rate unless source, window, and denominator match.

| Signal | Capture | Decision |
|---|---|---|
| Platform impressions | Baseline immediately before an approved post; then 24-hour and 7-day snapshots | Describe observed platform reach only |
| Repository referrer visits | Source-matched observations at the same snapshots | Use only as an inspection proxy, not verified reading |
| Qualified technical replies | URLs plus themes; no PII copied into repo | Update FAQ/proof only when evidence supports it |
| Decision-guide objections | Exact linked comments | Revise the guide before broader distribution |
| Permission requests | Owner-controlled count and source | Decide whether to create a real usage grant |
